# راهنمای شروع پروژهٔ زعفران برای Codex

هدف، طراحی و پیاده‌سازی یک کاتالوگ صادراتی سریع برای خریدار عمده است. خریدار باید بتواند از جست‌وجو مستقیماً به یک نوع زعفران برسد، ظاهر و تفاوت آن را ببیند و اطلاعات تماس شرکت را پیدا کند. نسخهٔ اول قیمت عمومی، سفارش اینترنتی یا پنل ترجمه ندارد.

## بسته را چطور استفاده کنم؟

پوشهٔ `saffron-brief` را در ریشهٔ مخزن بگذار و متن زیر را در Codex اجرا کن. در مخزن موجود، ابتدا وضعیت فایل‌ها و دستورهای پروژه را بررسی کن. پوشهٔ مستندات می‌تواند کنار کد باقی بماند.

> تمام فایل‌های Markdown پوشهٔ saffron-brief را بخوان. سایت کاتالوگ پنج‌زبانه را مطابق این قرارداد بساز. از ترتیب مراحل و تست‌های 06 استفاده کن. نمونهٔ فارسی و انگلیسی را از یک قالب مشترک بساز، سپس همان مسیر را برای هر پنج زبان کامل کن. برای دمو از متن‌های 03 استفاده کن. اگر اطلاعات مالک آماده نیست، نسخهٔ پیش‌نمایش را کامل کن و موارد باقیمانده برای انتشار را گزارش کن. معیار تکمیل، build موفق، لینک‌های سالم، اجرای تست‌ها و بررسی بصری خروجی واقعی در مرورگر است. نتیجه و آزمون‌های اجراشده را گزارش کن. انتشار عمومی و تغییر DNS مرحلهٔ جداگانهٔ مالک است.

## تصمیم‌های نسخهٔ اول

- سایت با Astro و TypeScript در زمان build به HTML تبدیل می‌شود. برای خواندن کاتالوگ از مرورگر درخواست API نداریم.
- پنج زبان ثابت در مخزن نگهداری می‌شوند. انگلیسی زبان پیش‌فرض و چینی ساده‌شده فرض اولیه است. صفحهٔ ریشه به انگلیسی می‌رود و تغییر زبان آگاهانه روی همان صفحه انجام می‌شود.
- برای ارتباط، ایمیل تجاری قابل کپی و لینک نوشتن ایمیل در نظر گرفته شده است. ثبت درخواست روی سرور هزینه و تعهد نگهداری جداگانه دارد؛ در این نسخه درخواست در سایت ذخیره نمی‌شود.
- چهار نوع محصول صرفاً دادهٔ نمونه هستند. دامنه، نام برند، نقش واقعی شرکت، محصولات قابل عرضه، مقصدها، مدرک‌ها، عکس‌ها و ایمیل باید از مالک کسب‌وکار برسد. بدون این موارد پیش‌نمایش قابل ساخت است.
- طراحی و ارزیابی در مرورگر انجام می‌شود. قرارداد ظاهری در سند 02 آمده است.

محتوای این بسته راهنمای اجراست. آمار سرعت و کیفیت شبکه بعد از ساخت و روی دامنهٔ واقعی قابل اندازه‌گیری‌اند.
