# کاتالوگ زعفران

پیاده‌سازی استاتیک Astro و TypeScript مطابق Docs؛ پنج زبان و ۴۰ صفحه.

## اجرا

Node مطابق `.nvmrc`، سپس `npm ci` و `npm run dev`.
کنترل: `npm run check`، `npm test`، `npm run build`.
مشاهده خروجی: `npm run preview`.

ترجمه‌ها در `src/data/copy.json` هستند. داده اولیه از Docs/03-copy.md با `node generate.mjs` استخراج شده؛ اجرای دوباره این دستور تغییرات ترجمه را بازنویسی می‌کند. مسیرها، محصولات و تنظیمات در `src/lib/content.ts` و قالب مشترک در `src/pages/[...path].astro` قرار دارند.

## انتشار

متغیرهای نمونه در `.env.example` هستند. پیش‌نمایش noindex دارد و ایمیل نمونه قابل ارسال نیست. حالت production عمداً تا اضافه شدن عکس‌های واقعی، ثبت حق استفاده و تکمیل اطلاعات مالک مسدود است. این یک پیش‌نمایش است، نه نسخه تأییدشده برای انتشار.

Cloudflare Pages: build برابر `npm run build` و output برابر `dist`. ریدایرکت ریشه در `_redirects` است. رفتار HTTP 301 و 404 باید روی Pages بررسی شود. هیچ انتشار عمومی یا تغییر DNS انجام نشده است.

موارد موردنیاز مالک: نام برند، دامنه، ایمیل واقعی، چهار محصول تأییدشده، عکس دارای مجوز، نقش واقعی شرکت و بازبینی ترجمه‌ها. ارزیابی شبکه بازارها و ارسال/دریافت ایمیل واقعی پس از استقرار انجام می‌شود.

## وضعیت بررسی این نوبت

- بررسی TypeScript: موفق، بدون خطا یا هشدار.
- build: موفق؛ ۴۰ صفحه محتوایی و 404.
- آزمون HTML تمام صفحات، لینک داخلی، canonical، alternate، sitemap و ایمیل غیرفعال: موفق.
- بازکردن پیش‌نمایش با مرورگر داخلی: خطای اتصال `ERR_CONNECTION_TIMED_OUT`؛ پذیرش بصری هنوز تأیید نشده است.
- آزمون Lighthouse، شبکه بازارها، دامنه واقعی، ماتریس کامل دستگاه‌ها و آزمون منفی production هنوز انجام نشده‌اند.
- مدل تصاویر تأییدشده و مسیر فعال‌سازی production نیاز به تکمیل دارد؛ توقف production فعلاً عمدی و قطعی است.

## ارتقای نسخهٔ ارائه

صفحه مستقل فهرست محصولات حذف شده است؛ منو به بخش `#products` خانه اشاره می‌کند. تعداد صفحات محتوایی اکنون ۳۵ است. جزئیات هر محصول حفظ شده است. متن بخش‌های جدید در `src/data/editorial.json` قرار دارد.
تصویر `public/images/editorial-saffron.webp` با imagegen برای همین پیش‌نمایش ساخته شده و عکس محصول واقعی یا مدرک کیفیت نیست. نسخهٔ 780 پیکسلی برای موبایل ارائه می‌شود. تصویر فقط در بخش‌های فضاساز استفاده شده است.
